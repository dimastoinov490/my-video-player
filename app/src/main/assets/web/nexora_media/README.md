# Nexora Media

Автономный проект, интернет не нужен.

Запуск: распакуйте архив и откройте `index.html` в Chrome (ПК или Android).
Все ресурсы (шрифты, видео, аудио) лежат внутри папки проекта.
Состав: index.html, style.css, app.js, fonts/ (Roboto), media/ (видео и аудио).
Фото в галерее и иконки генерируются кодом (SVG), отдельных файлов не требуют.
